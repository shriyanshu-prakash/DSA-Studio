# DSA Studio

An interactive **Data Structures and Algorithms visualizer** built with Python and Tkinter. Explore common data structures and algorithms through a graphical interface, perform operations, and understand how they work.

## ✨ Features

- **Stack & Queue** — perform basic operations and manage elements.
- **Linked List** — work with singly and doubly linked lists.
- **Binary Search Tree (BST)** — insert, search, delete, and traverse nodes.
- **AVL Tree** — explore balanced-tree operations and traversals.
- **B-Tree** — insert and search for elements.
- **Min Heap** — manage elements using heap operations.
- **Sorting Lab** — explore Bubble, Selection, Insertion, Merge, and Quick Sort with step-by-step visualization.
- **Searching Lab** — experiment with Linear and Binary Search.
- **Graph Lab** — explore BFS, DFS, and Dijkstra's shortest-path algorithm.
- **Light & Dark Themes** — switch between themes for a comfortable experience.

## 🛠️ Tech Stack

- **Language:** Python
- **GUI:** Tkinter
- **Version Control:** Git & GitHub

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or later recommended
- Tkinter (usually included with standard Python installations)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/shriyanshu-prakash/DSA-Studio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DSA-Studio
   ```

3. Run the application:

   ```bash
   python main.py
   ```
